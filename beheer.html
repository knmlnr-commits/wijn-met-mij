Opslaan op de site

De site draait op GitHub Pages. Om je gegevens op te slaan heeft deze pagina eenmalig een toegangssleutel nodig; die blijft alleen in je eigen browser staan.

GitHub-koppeling

Maak er een aan via github.com/settings/personal-access-tokens/new. Kies bij Repository access alleen deze repository, en zet bij Repository permissions het onderdeel Contents op Read and write. Meer is niet nodig.
